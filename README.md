One line roasting an alarm clock that rings at 6 AM on a Saturday morning,
written by a small program. `main.ts` writes a single line to
`/output/entry.txt`.

The roast:

> My alarm clock rang at 6 AM on a Saturday like it had just been named employee of the month — I hit snooze and it smirked, 'See you in nine minutes, boss.'

## Run

```sh
node main.ts
```

It writes the roast to `/output/entry.txt` (1–200 characters, a single line).
